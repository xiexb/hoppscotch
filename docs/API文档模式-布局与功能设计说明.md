# API 文档编辑页面 - 布局与功能设计说明

---

## 一、整体布局结构(文档编辑状态)

页面采用 **接口地址栏 + 主体单列纵向滚动** 的布局模式，从上至下分为 4 个区域：

```
┌─────────────────────────────────────────────────────────┐
│ 1. 接口地址栏（Method + URL + 操作按钮）                │
├─────────────────────────────────────────────────────────┤
│ 2. 接口元信息区（标题、状态、说明、责任人）                │
├─────────────────────────────────────────────────────────┤
│ 3. 请求参数区（Tab 切换 + 参数表格）                    │
├─────────────────────────────────────────────────────────┤
│ 4. 返回响应区（状态码 Tab + Body 结构定义）             │
└─────────────────────────────────────────────────────────┘
```

---

## 二、各区域功能详述

### 区域 1：接口地址栏
- **Method 下拉**：`POST`（带颜色标识：GET 蓝/POST 橙/PUT 黄/DELETE 红）
- **URL 输入框**：`/wifi/report/record`，支持路径变量 `{变量参数}`
- **保存按钮**（紫色高亮主操作）保存后进入 文档预览
- **调试按钮**：跳转调试模式 Tab

### 区域 2：接口元信息区
- **标题行**：接口中文名（`wifi开门记录上报`）+ 状态徽标（`开发中`，可下拉切换：设计中/开发中/测试中/已发布/废弃）
- **Markdown 描述**：接口说明，支持 Markdown 渲染
- **三列字段**：
  - 责任人（人员选择器）
  - 标签（多选 Tag，支持回车创建）
  - 前置 URL（"继承父级" + "跟随父级目录设置（推荐）"双下拉）


### 区域 3：请求参数区  和调试模式样式保持一致

- 底部辅助操作：`+ 添加示例` 

---

### 区域 4：返回响应区
- **左侧响应 Tab**：`200 成功`（绿色），可 `+` 新增其他状态码（400/401/500 等）
- **元信息**：HTTP 状态码、名称、内容格式（JSON/XML/HTML…）、`application/js...` MIME 类型
- **Body 结构树**：
    JSON 模式（Schema 结构树）：
    右上角显示 application/json MIME 标识（带编辑圆圈图标）
    内容区标题：数据结构
    树形 Schema 编辑器，每行列结构：
    列 说明
    展开箭头 + 字段名  蓝色（根节点显示"根节点"）
    类型  object / string / integer / number / boolean / array / file，蓝色文字
    Mock  Mock 规则输入框（如 @string）
    中文名 字段中文说明
    说明  字段英文/详细描述
    － 删除 / ＋ 添加子字段  行尾操作按钮
    根节点类型为 object，初始显示"没有字段 添加"（点击添加插入子字段）
    子字段行有缩进，支持无限嵌套
    底部辅助操作：+ 添加示例


- **底部辅助操作**：`+ 添加示例` `+ 添加描述` `+ Headers`

## 一、整体布局结构（预览模式）

```
┌─────────────────────────────────────────────────────────┐
│ 1. 接口标题栏（名称 + Method + URL + 状态 + 操作按钮）  │
├─────────────────────────────────────────────────────────┤
│ 2. 元信息行（创建时间、更新时间、作者、迭代、关联等）        │
├─────────────────────────────────────────────────────────┤
│ 4. 请求参数区                                           │
│    ├── Authorization 鉴权说明                           │
│    ├── Path 参数表                                      │
│    ├── Header 参数表                                    │
│    └── Body 参数表（左：字段列表 | 右：JSON 示例）      │
├─────────────────────────────────────────────────────────┤
│ 5. 返回响应区                                           │
│    └── 响应 Tab + Body 字段树（左：字段 | 右：示例）    │
└─────────────────────────────────────────────────────────┘
```

## 二、各区域功能详述

### 区域 1：接口标题栏
- **左侧**：
  - 接口中文名（`新增钥匙`，大标题）
  - 状态徽标（`开发中`，蓝色胶囊）
  - 收藏、分享、更多操作图标（✩ 🔗 ···）
- **Method + URL 行**：
  - Method 徽标（`POST`，橙色胶囊）
  - 完整 URL 路径（灰色可点击复制）
  - `+ 开发中` 次要标识
- **右侧操作按钮组**：
  - `手调试`（主要蓝色按钮）
  - `生成行代`
  - `复制`

### 区域 2：元信息行
单行横向展示，使用灰色小字 + 间隔符分隔：

| 字段 | 示例值 |
|---|---|
| 创建时间 | 2022年4月15日 |
| 修改时间 | 修改方向 2章 |
| 修改者 | wk.Hu |
| 迭代/过期 | 迭代版本信息 |
| 相关测试 | 测试用例数量 |
| 负责人 | 显示头像或名称 |
| 未设置 | 其他可选字段占位 |

### 区域 4：请求参数区（只读展示）

#### 4.1 Authorization 鉴权说明
折叠面板 `∨ Authorization`，展开后显示：
- 说明文字：`在 Header 添加参数 Authorization，其值为方 Bearer 之后拼接 Token`
- 示例行：`Authorization: Bearer ••••••••••••••`（脱敏展示）

#### 4.2 Path 参数
小标题 `Path 参数`，每行展示：
```
参数名（蓝色）  类型（灰色）  必填徽标（橙色）
deviceCode      string        必填
```

#### 4.3 Header 参数
小标题 `Header 参数`，字段格式：
```
参数名（蓝色）  类型（灰色）  必填徽标（橙色）
                示例：示例值（灰色小字，次行缩进）
```
- `Accept-Language  string  必填`  → 示例：`zh-CN`
- `Authorization    string  必填`  → 示例：`Bearer 627f02ac-a39f-44fe-9d1d-8d75d8a7f46`（长串，脱敏）

#### 4.4 Body 参数（两列布局）
**左列（约 60% 宽度）**：字段列表

小标题 `Body 参数 application/json`（灰色 MIME 标注）

| 字段名 | 类型 | 必填 |
|---|---|---|
| registerType | integer | 必填（橙色徽标） |
| keyType | integer | 必填 |
| keyInfo | string | 必填 |
| userRole | integer | 必填 |
| userFlag | string | 必填 |

**右列（约 40% 宽度）**：JSON 示例代码块

```json
{
  "registerType": 1,
  "keyType": 2,
  "keyInfo": "1A45A3",
  "userRole": 1,
  "userFlag": "186333"
}
```
- 深色代码块背景，JSON 语法高亮（key 白色，string 橙色，number 绿色）

### 区域 5：返回响应区

#### 5.1 响应状态 Tab 栏
横向 Tab，默认选中 `200 超时链接`，其余：`0 期待响应` | `0 人积累响应`

#### 5.2 响应元信息行
`HTTP 状态码: 200   application/json`（MIME 类型灰色文字）

#### 5.3 响应 Body（两列布局）

**左列**：字段层级树（支持嵌套）

| 层级 | 字段名 | 类型 | 必填 |
|---|---|---|---|
| 一级 | result | boolean | 必填 |
| 一级 | code | integer | 必填 |
| 一级 | msg | string | 必填 |
| 一级 `▸` | data | object | 必填 |
| 二级（缩进） | mogId | string | 必填 |
| 二级（缩进） | keyCode | integer | 必填 |

- `data` 前有展开箭头 `▸`，可折叠子字段
- 每行右侧显示橙色 `必填` 徽标

**右列**：JSON 示例代码块

```json
{
  "result": true,
  "code": 0,
  "msg": "OK",
  "data": {
    "mogId": "72",
    "keyCode": 4
  }
}
```
- 与 Body 参数区一致的语法高亮风格

## 四、与编辑视图的核心差异

| 特性 | 文档视图（当前） | 编辑视图 |
|---|---|---|
| 可交互性 | 只读展示 | 可编辑所有字段 |
| Body 格式选择 | 仅显示已选类型 | 显示类型切换条 |
| 参数布局 | 按分组展示（Path/Header/Body） | 统一 Tab 切换 |
| 示例展示 | 右侧固定双列代码块 | 可折叠示例入口 |
| 嵌套结构 | 树形缩进展示 | 可编辑 Schema 树 |
